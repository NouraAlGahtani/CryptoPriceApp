₿ Crypto Price App

Hi! 👋

This is a simple Crypto Price App that displays cryptocurrency prices and provides a quick way to keep up with the market.

The project was built to practice working with APIs, JavaScript, and dynamic data, fetching real-time cryptocurrency information and displaying it through a simple interface. 📈

✨ Features

* 💰 View cryptocurrency prices
* 🔄 Fetch data through a cryptocurrency API
* 📊 Display live market information
* 🌐 Simple and responsive web interface

⚠️ API Note

The API used in this project is limited to the first 5 cryptocurrencies.

A fancier API = fancier results ;) ✨
